- **Browser Operator sessions start with Claude in Chrome.** Start a local Claude agent session with a title beginning `[Browser Operator]` to load the Chrome extension's tools. A project manager can start one after you approve the launch. Chrome tool calls ask for single-use approval at every autonomy level and also use the extension's site permissions. CodeDen strips leading role tags from automatically derived titles and records the opt-in when a new session is created.
