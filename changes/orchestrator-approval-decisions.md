- **The orchestrator can decide eligible plan approvals.** It can list pending requests across projects and record its reasons in inbox history. A delegable plan-mode tool approval has no command, listed paths, hook, URL, single-use restriction, Chrome consent, or sensitive-text match. Its tool input is absent or a plain object with only the optional `plan` key. PM plan cards are delegable when all steps are tier 0 or 1. All other requests, including file changes and guard cards, require the owner.
