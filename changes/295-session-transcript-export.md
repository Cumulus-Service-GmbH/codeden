- **Share a session as Markdown.** The session's **⋯** menu (in the thread header and on its sidebar row) has **Copy as Markdown** and **Download as Markdown**, to paste how an agent solved something into an issue, a pull request or a write-up. The file starts with the session's project, provider, branch, issue, pull request, result and cost (labelled as in the app), then lists every turn: messages under who sent them, replies, plans, todos, questions, approvals, one line per tool call and subagent threads in collapsible blocks. Reasoning, tool output and diffs are left out.
