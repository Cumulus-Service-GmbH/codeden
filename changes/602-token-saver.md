- **Token saver.** Settings → General → Token saver adds a short note to each session's system prompt that asks for terse answers, the least code and narrow searches, at Lite, Full or Ultra (off by default). Exact technical terms and the words not, never, no and only are kept, and security warnings, irreversible steps and text that leaves the session stay in full sentences. Each role can have its own default, and a project can override it in its settings. Every session CodeDen starts gets it (yours, project managers, the orchestrator, the factory and automations) on every provider. It applies to sessions started or resumed after a change; Claude Code and Codex keep it on resume and after compaction, and ACP agents get it in front of the first prompt. (#602)
