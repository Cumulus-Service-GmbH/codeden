- **Review with another agent.** Get an independent, read-only second opinion on any agent session's changes, as the software factory gets for its own work. **Review with another agent…** in the session's ⋯ menu, the command palette or under its pull request in the GitHub panel starts a new session, on another provider when one is signed in. It gets a copy of the session's code and a review brief, runs with read-only permissions, and ends with a verdict (**Approve** or **Request changes**) and findings ranked by severity. Add an optional focus for the reviewer. The reviewed session is unchanged, and the review's header links back to it as **Review of …**.
