- **The daily digest no longer talks about the scout when nothing is held for it.** In a software factory, or a dark factory whose scout runs no rounds, filing a review follow-up made the digest read "Review follow-ups: 0 held for the scout, 1 filed; 0 held now". It now reads "Review follow-ups: 1 filed." A dark factory that holds follow-ups for its scout keeps the full line.
