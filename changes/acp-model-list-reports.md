- **Cursor's and the Antigravity CLI's model lists no longer go back to an older session's.** When a running session's options changed, CodeDen reported that session's whole setup from when it started, so its older models and modes could replace a newer session's. Now only the options that changed are reported. The Antigravity CLI's model list now shows before your first session, and after a model change the session says that the model list updates at the next session.
