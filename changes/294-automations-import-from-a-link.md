- **Import automations from a link.** The Automations page's **Import** dialog has a **Link** tab. Paste an https link to a `.md` or `.zip` file, a GitHub file page or a public gist, and CodeDen downloads it once and shows the usual preview. Sharing an automation is now a matter of handing out its link. Every `.md` file in a gist is offered, a GitHub file page is fetched from its raw address, and GitHub's **Download ZIP** links work too. The import creates exactly what you previewed, all switched off. The download sends no cookies, tokens or GitHub credentials, accepts only https (redirects included), stops after 15 seconds or 1 MB, and reaches only the public internet: links, redirects and DNS answers that lead to this computer or a private network are refused.
